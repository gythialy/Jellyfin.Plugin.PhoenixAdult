PhoenixAdult

This metadata agent helps fill Jellyfin/Emby with information for your adult videos by pulling from the original site.

Sites behind Cloudflare (JAVLibrary, Babepedia, …) are fetched through FlareSolverr. Leave empty to disable the fallback.
One rule per line, format: host=referer. The plugin ships with defaults for image CDNs that reject requests without a Referer (phncdn.com, javbus.com) — they are present here by default, so you can edit them. Set the value after “=” to empty to disable a host.

JavDB

JavDB supplies movie metadata, covers and actor portraits. Censored titles work without an account; actor pages and uncensored titles require a logged-in session. See the JavDB guide in the plugin docs for details.

JavDB guide (docs/javdb.md)

Paste the whole Cookie request header of a logged-in javdb.com session. Used only for actor pages and uncensored titles; without it those pages are skipped and censored titles keep working.
How to get the cookie
  1. Sign in to javdb.com in a desktop browser and open any actor or uncensored movie page.
  2. Open DevTools (F12) → Network, reload the page, select the HTML request (document type).
  3. In Request Headers copy the value after Cookie: — it looks like the example above.
  4. Paste it here, then press “Test cookie” to verify before saving.

The session expires on the JavDB side (usually weeks). Signing in requires a captcha, so the plugin cannot renew it automatically — press “Test cookie” now and then, and paste a fresh value when it reports expired. The value is stored in the plugin configuration on this server, so treat this field as a credential and clear it when you no longer need it.

Many Japanese actresses have no portrait in any public database. When every portrait source comes back empty, the cover of one of the actor's JavDB titles is used instead (labelled "JavDB (cover)"). Turn this off if you prefer a missing photo over a cover image.
When a file name contains an ID, every source registered for that ID family is queried in parallel and the results are merged. A site name that merely looks like an ID label (e.g. HEYZO-0929 and the site "Heyzo") does not restrict the search to that single site.
